# MiHoo 九系壁球联赛赛程管理系统

面向 2026 年 11 月 21 日清华大学九系壁球俱乐部联赛的可运行网页系统。管理员通过高随机私密链接完成名单、抽签、成绩、排场和积分管理；观众通过独立公开链接实时查看。

## 当前状态

- 源代码和运行环境已在本机完成逻辑测试与浏览器端到端验收。
- 尚未使用用户的云服务账号部署，因此目前**没有外部公网链接**。
- 启动后控制台会输出本机管理员链接和观众链接。

## 快速启动

要求 Node.js 22 或更高版本，无需安装第三方依赖。

```powershell
node server.mjs
```

控制台示例：

```text
观众链接: http://127.0.0.1:8787/view
管理链接: http://127.0.0.1:8787/admin/<私密令牌>
```

管理员链接具有全部编辑权限，只应发送给赛事核心成员。令牌保存在 `work/data/auth.json`；正式部署建议通过 `ADMIN_TOKEN` 环境变量固定。

## 功能

- Excel 导入姓名、院系、组别三列，自动生成稳定内部 ID。
- 四个组别独立安全随机抽签，预览、手动交换、确认锁定。
- 新手组 4 小组单循环、实时排名、人工并列裁决、随机八强。
- 进阶组 8 名种子分别进入 8 个 16 强位置，16 人随机资格赛。
- 完整横向签表、晋级自动推进、半决赛负者进入季军赛。
- 修改早期成绩时显示受影响下游比赛，确认后按依赖顺序撤销。
- 四片场地自动排赛，识别午间禁排、场次重叠、选手冲突和超时。
- 八个联合参赛单位的可配置团体积分规则与实时榜单。
- JSON 完整备份、上一版恢复、Excel 导出和打印签表。
- 服务端令牌校验、版本号原子保存、SSE 实时同步。

## 数据与部署

数据保存在服务端 JSON 文件中，不是浏览器 `localStorage`。每次保存先写临时文件，再原子替换正式文件，并保留上一版快照。观众写入请求会被服务端直接拒绝。

详见：

- `outputs/部署说明.md`
- `outputs/使用手册.md`
- `outputs/测试记录与待办.md`

## 技术结构

- `server.mjs`：静态文件、管理员令牌、原子存储、SSE 推送。
- `public/src/model.js`：赛事数据结构、选手与院系模型。
- `public/src/engine.js`：抽签、排名、签表、晋级、积分和纠错。
- `public/src/schedule.js`：四场地时间窗、依赖、休息与冲突检查。
- `public/src/xlsx.js`：浏览器端 `.xlsx` 读写。
- `public/src/ui.js`：管理员与观众界面。
- `public/src/main.js`：交互、保存、同步和文件导入导出。

## 赛制边界

当前标准签表按需求固定为：

- 新手男子：17 人，5/4/4/4 分组，八强。
- 新手女子：19 人，5/5/5/4 分组，八强。
- 进阶男女：各 24 人、8 名种子、16 人资格赛。

管理员可以修改选手信息，但若人数或进阶种子条件不再满足标准配置，系统会阻止抽签而不是生成错误签表。具体待确认事项见测试记录与待办。
