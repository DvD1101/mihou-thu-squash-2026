# MiHoo 九系壁球联赛系统部署说明

## 1. 当前实际部署状态

源代码已经完成本机运行和浏览器验收。由于本次没有提供 Supabase、Render、Fly.io、云主机或其他云平台账号与权限，**尚未完成公网部署**，也没有虚构管理员链接或观众链接。

本机可用链接由服务端启动时输出：

- 观众：`http://127.0.0.1:8787/view`
- 管理员：`http://127.0.0.1:8787/admin/<私密令牌>`

同一 Wi-Fi 下的其他设备需将 `HOST` 设为 `0.0.0.0`，并使用运行电脑的局域网 IP。正式现场更建议部署到带持久磁盘的云服务，确保外网和手机网络可访问。

## 2. 本机启动

要求 Node.js 22 或更高版本。

```powershell
cd <项目目录>
node server.mjs
```

如需固定管理员令牌：

```powershell
$env:ADMIN_TOKEN = node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
node server.mjs
```

若未设置 `ADMIN_TOKEN`，系统首次启动会生成高随机令牌并保存到 `work/data/auth.json`。不要公开该文件或管理员链接。

## 3. Docker 部署

```powershell
docker compose up -d --build
```

查看管理员链接：

```powershell
docker logs mihou-squash-2026
```

数据保存在 Docker 命名卷 `mihou-data`。不要使用无持久卷的临时容器，否则重新部署会丢失赛事结果。

## 4. Render 部署

项目包含 `render.yaml`：

1. 将源代码推送到私有 Git 仓库。
2. 在 Render 创建 Blueprint，选择该仓库。
3. Render 会构建 Docker 镜像并挂载 1 GB 持久磁盘到 `/data`。
4. 在服务日志中查找“管理链接”，或在设备上通过保存的私密链接访问。
5. 将自定义域名绑定后，确保 HTTPS 已启用。

注意：Render 的持久磁盘属于付费能力；免费实例的文件系统不适合作为正式赛事数据库。

## 5. Fly.io / 普通云主机

项目已包含 `fly.toml`。典型流程：

```bash
fly launch --no-deploy
fly volumes create mihou_data --size 1
fly secrets set ADMIN_TOKEN=<新的高随机令牌>
fly deploy
```

普通 Linux 云主机可以使用 Docker Compose，并在前面配置 Caddy、Nginx 或云平台 HTTPS 入口。不要把数据目录放在容器临时层。

## 6. 环境变量

| 变量 | 作用 | 建议 |
|---|---|---|
| `ADMIN_TOKEN` | 管理员写入令牌 | 至少 32 字符高随机值；只在正式部署设置一次 |
| `HOST` | 监听地址 | 云部署固定为 `0.0.0.0` |
| `PORT` | 监听端口 | Render 示例为 `10000`，Docker Compose 为 `8787` |
| `DATA_DIR` | 持久数据目录 | 云部署固定为挂载磁盘 `/data` |

## 7. 数据安全

- 管理员链接不进入观众页面、静态资源或公开配置。
- 所有写请求都在服务端校验私密令牌。
- 保存时校验客户端版本，冲突返回 409，不覆盖另一窗口的新数据。
- 正式文件通过临时文件加原子重命名保存。
- 每次保存前保留 `state.previous.json`。
- 观众只能读取和订阅 SSE，不能调用写入接口。

## 8. 正式启用检查

1. 打开管理员链接，在设置中下载完整 JSON 备份。
2. 清空模拟数据。
3. 导入真实名单，确认四组人数、外院系和院系映射。
4. 为进阶男女各设置 8 名种子，确认来自 8 个不同参赛单位。
5. 完成抽签预览并确认。
6. 执行自动排场，处理全部冲突和未安排比赛。
7. 用另一台手机打开观众链接，确认实时同步。
8. 在正式比赛前再下载一次完整备份。

## 9. 建议的运维措施

- 比赛当天保留一台主笔记本和一台备用设备，但只在一个窗口录入，避免并发操作。
- 每小时从设置页下载一次 JSON 备份。
- 不把管理员链接发到群聊、朋友圈或公开投屏。
- 赛后保留完整 JSON、Excel结果和操作记录截图。
