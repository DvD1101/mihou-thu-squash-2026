## 4. 尚未解决或需赛事方确认

1. **九个院系正式名单未提供**：默认八单位为可编辑示例，正式启用前必须按主办方准确名称和别名修改。
2. **积分规则未最终确定**：系统未硬编码规则，默认 1–8 名分值仅用于演示；赛事方需确认每档分值和并列处理。
3. **进阶组标准人数固定为 24 人、8 种子**：这是当前需求的核心签表条件。若最终人数变化，需要另行定义轮空数量或资格赛规模。
4. **新手组标准淘汰赛固定八强**：当前支持 17 与 19 人四组、前二晋级八强。若人数变化导致晋级人数不是 8 人，需调整赛制配置。
5. **免费版同步间隔**：Netlify 免费版使用约 10 秒自动同步；本机 Node 版支持即时 SSE。
6. **备份保留范围**：云端只自动保留上一版，没有跨天自动版本历史；建议赛事当天人工下载多个 JSON 备份。
7. **权限模型**：按要求采用高随机私密管理员链接，没有密码和第二重认证；链接泄露等于编辑权限泄露。
