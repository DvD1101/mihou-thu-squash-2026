# MiHoo 九系壁球联赛系统使用手册

## 1. 角色与链接

- 管理员链接：可编辑名单、抽签、成绩、排场、积分和数据。
- 观众链接：只读，可实时看到最新结果。
- 两个链接用途独立。管理员链接相当于编辑密钥，不要公开。

## 2. 赛前准备

### 2.1 导入名单

1. 进入“名单管理”。
2. 点击“下载 Excel 模板”。
3. 只填写“选手姓名、院系、组别”三列。
4. 删除四条示例记录。
5. 返回系统导入 `.xlsx`。
6. 检查导入预览中的四组人数和错误提示。

系统会自动识别院系别名、生成稳定内部 ID，并把外院系标记为不产生团体积分。不要把种子序号、签位、电话等字段塞进 Excel。

### 2.2 维护特殊身份

- 校友：在选手行点击“编辑”，勾选“校友”，并确认积分归属。
- 外院系：院系无法映射到八个联合单位时自动成为外院系。
- 院系映射：设置页可编辑八个单位及别名。例如医学院和万科卫健学院合并为一个单位。
- 进阶种子：进入进阶组名单，编辑选手并勾选“种子”。男女各需 8 人，同一参赛单位可以选择多名。
- 批量操作：在名单管理中勾选多名选手，可批量设为种子、批量取消种子或批量删除。批量种子只检查每组 8 人上限；已经进入签表的选手不能被批量删除。

### 2.3 抽签

1. 进入“抽签”。
2. 新手组点击“一键随机抽签”，预览人数分布。
3. 进阶组确认 24 人和共 8 名种子后点击抽签。种子可来自相同或不同参赛单位。
4. 可在预览中交换小组选手或种子/资格赛签位。
5. 确认后签表锁定，所有对应比赛生成。

若已录入成绩后重新抽签，系统会显示警告并要求确认。该操作会清除本组全部结果。

### 2.4 自动排场

1. 完成签表生成。
2. 进入“比赛日调度台”。
3. 确认默认时长与休息时间。
4. 点击“自动排场”。
5. 检查红色冲突框和“待安排”数量。

系统只使用 1–4 号场，禁止 12:00–14:00 排赛。进阶组默认 17 分钟，包含 2 分钟热球；新手组默认 7 分钟。若容量不足，不会伪造完整方案，而会保留未安排警告。

## 3. 比赛现场

### 3.1 开始和结束比赛

- 在调度台点击“开始”，记录实际开赛时间。
- 比赛结束时，在调度台、小组赛或签表中点击胜者姓名。
- 弹窗中再次点击选手卡片确认。
- 系统自动记录完成时间、胜者和负者，并释放场地。

### 3.2 新手组排名

- 优先按胜场排序。
- 两人同胜场时比较相互胜负。
- 三人及以上循环或规则无法区分时显示“排名待裁决”。
- 管理员点击“人工确定并列排名”，安排顺序并填写原因。
- 小组完成且无待裁决后，前两名自动标记晋级。

### 3.3 生成八强

四个小组全部完成且排名确定后，进入新手组“小组赛”，点击“随机生成八强签表”。系统会避免同组第一与第二首轮相遇。

### 3.4 修改已录入结果

1. 点击该场比赛的当前负者，或在已完赛行点击“撤销”。
2. 系统列出已开始或已完成的后续比赛。
3. 确认后按依赖顺序清除受影响结果。
4. 重新确认正确胜者。

看不到影响清单时不要继续盲目修改；先刷新页面确认最新版本。

如果同一管理员链接在两个窗口同时录入，第二个窗口会提示“数据已自动合并并保存”。系统会保留另一个窗口的更新，并把当前操作重新应用到最新状态，不需要重新点击裁决。

### 3.5 季军赛

两场半决赛完成后，负者自动进入季军赛。季军赛在签表页下方独立显示。

## 4. 团体积分

- 进入“团体积分”。
- 管理员点击“编辑积分规则”调整第1–8名分值。
- 外院系获得前八名时该名次分值为空，不顺延给后一名。
- 校友积分按管理员指定的原院系或计分单位归属。
- 榜单实时显示八单位总分、各组得分和当前排名。

默认分值只是可编辑示例，正式赛前必须由赛事负责人确认。

## 5. 投影、打印和导出

- 签表页“全屏投影”适合投屏。
- “打印签表”打开浏览器打印，可选择 PDF。
- 设置页可以导出全部结果工作簿、小组赛成绩、淘汰赛结果、积分榜、名单和 JSON 备份。

## 6. 数据安全

- 每次保存成功后才会更新页面，不会把失败伪装成成功。
- 网络断开时出现红色提示并暂停保存。
- 设置页可下载完整 JSON 备份。
- 服务端保留上一版快照，可尝试恢复上一版。
- 清空数据和载入模拟数据均需二次确认。

## 7. 现场操作建议

- 上午开始前：确认名单、种子、抽签、排场、备份。
- 每场结束：立即录入成绩并确认下一场。
- 午休前：下载一次备份，检查下午待安排数。
- 每组决赛后：打印/导出签表和积分榜。
- 全天只在一个管理员窗口录入，其他设备使用观众链接。

## 8. 常见问题

### 管理员链接打不开

确认服务端仍运行，且链接未被截断。令牌保存在 `work/data/auth.json` 或部署环境变量 `ADMIN_TOKEN`。

### 观众页面未更新

查看顶部“实时同步”状态。恢复网络后系统会自动重新拉取最新版本。

### 抽签按钮不可用

新手组至少需要 4 人；进阶组必须是 24 人且共有 8 名种子，同单位可以有多个种子。

### Excel 无法导入

确认文件为 `.xlsx`，第一张表包含“选手姓名、院系、组别”表头，并使用新版 Chrome 或 Edge。

### 自动排场仍有未安排比赛

这是容量或依赖约束的真实提示。缩短预计时长、调整先前比赛或人工安排未排比赛，并继续检查红色冲突。
